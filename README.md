# 🍎 Fruit Card

A simple and attractive **Fruit Card** project created using **HTML and CSS**.

## 📌 Project Description

This project was created as an assignment to practice HTML and CSS. It displays a fruit card with images and styling to create a clean and visually appealing design.

## 🚀 Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
Fruit-Card/
│
├── Asstes/
│   └── Images
│
├── index.html
├── style.css
└── README.md
```

## ✨ Features

* Simple and clean design
* Fruit images
* Styled card layout
* HTML and CSS only
* Beginner-friendly project

## 🛠️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in your browser.
